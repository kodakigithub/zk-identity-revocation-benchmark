# Benchmark results (raw data)

CSV files in this directory are the raw inputs to the paper's Results section
(Sections VI–VII). They are regenerated by the scripts in `benchmarks/`; see
`docs/README.md` for exact commands.

| File             | Produced by                          | Columns                                            |
| ---------------- | ------------------------------------ | -------------------------------------------------- |
| `gas.csv`        | `npm run bench:gas`                  | `scheme,operation,revocation_count,gas_used`       |
| `proof_time.csv` | `npm run bench:proof-time`           | `scheme,trial,time_ms,memory_delta_bytes`          |
| `storage.csv`    | `npm run bench:storage`              | `scheme,revocation_count,storage_slots_used,cumulative_gas` |
| `mobile.json`    | holder-wallet `/benchmark` page      | per-device on-device proving trials (copied manually) |

Environment for the committed results: Node.js v23.11.1, Hardhat local network
(automine), circom 2.2.3, Groth16 over BN128. Record CPU model when writing the
paper's evaluation section.
